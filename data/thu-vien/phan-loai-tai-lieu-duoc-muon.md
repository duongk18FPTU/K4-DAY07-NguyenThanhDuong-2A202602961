# Circulation regulations for library materials

| No. | Material type | Circulated? | Circulation location | Notes |
| --- | --- | --- | --- | --- |
| 1 | General print books | Circulated | Self-check machines (1st & 2nd floor), circulation desk (1st floor), 24/7 book return machine | |
| 2 | Reference materials and print journals | **Uncirculated** | Not applicable | Read at the library only |
| 3 | Audiovisual materials (CDs/DVDs) | Circulated | Circulation desk (1st floor) only | |
| 4 | Books in Course Reserve collection | Circulated | Circulation desk (1st floor) only | Checked out for **02 hours only**, 01 item per user per time |

## Requesting items that are checked out

Patrons can request items that are currently checked out via the online catalog.

Requests will **not** be accepted if the item is in the Course Reserve, is lost,
missing or non-circulating, if the patron's borrowing privileges are blocked, or
if the patron has reached the borrowing limit.

Once ready, the item will be held for **2 days**. If not picked up, the request
will be canceled. Only the requesting patron can pick up the item in person.

## Handling of materials

Patrons need to inform library staff at the circulation desk about any damage to
the materials before check-out and check-in.

Patrons are prohibited from misfiling or hiding library materials for personal
use, or bringing physical materials out of the library without going through
borrowing procedures as regulated.
